# RocketDock Next — Portable

Портативная Flutter/Dart-панель запуска приложений для Windows, по мотивам RocketDock 1.3.5.

## Портативность
- Настройки сохраняются в `data/settings.json` рядом с `RocketDockNext.exe`.
- Нет SharedPreferences, AppData или записи конфигурации в реестр.
- Сборочный скрипт создаёт `portable.mode`, `data/Icons`, `data/Themes`, `data/Backups`.
- Для переноса на другой компьютер скопируйте всю папку Release целиком.
- Приложения и документы, на которые ссылаются ярлыки, не копируются автоматически: на новом ПК проверьте пути/буквы дисков.

## Импорт RocketDock
В RocketDock 1.3.5 включите «Сохранять настройки в файле Settings.ini» на вкладке «Общие», закройте RocketDock и выберите файл `Settings.ini` через «Общие → Импортировать настройки RocketDock 1.3.5».

Импортёр разбирает формат 1.3.5 (кодировка cp1251, секции `[Software\\RocketDock]` и `[Software\\RocketDock\\Icons]`), переносит подтверждённые настройки и ярлыки, сохраняет пути к значкам и копирует соседние каталоги `Icons`, `Skins`, `Docklets` в `data/RocketDockAssets`. Пути к значкам внутри папки RocketDock перенаправляются на скопированные ресурсы. Неизвестные поля не угадываются. Если версия RocketDock хранит ярлыки в ином формате, диалог покажет предупреждение; тогда нужен реальный `Settings.ini` для точной настройки парсера.

Важные ограничения миграции:
- Ссылки на программы/папки переносятся как пути, но сами приложения не копируются.
- Абсолютные пути и буквы дисков могут отличаться на другом ПК.
- Скопированные Docklets сохраняются как данные, но RocketDock/ ObjectDock docklets не исполняются RocketDock Next автоматически.
- Автозапуск Windows отключён как системная интеграция, чтобы портативный режим не оставлял скрытых записей на компьютере.

## Сборка Windows
Требуются Windows 10/11 x64, Flutter stable, Visual Studio 2022 workload **Desktop development with C++** и Windows SDK.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\build_windows.ps1
```

Результат: `build\windows\x64\runner\Release\`. Переносите весь каталог Release, а не только EXE.

## Запуск
`RocketDockNext.exe` — окно настроек; `RocketDockNext.exe --dock` — сама панель (кнопка «Показать панель» запускает её отдельным процессом).

## Статус
Win32-слой (прозрачное окно, позиционирование, автоскрытие, мониторы, иконки, окна, меню) и импорт реального Settings.ini RocketDock 1.3.5 **написаны, но не компилировались и не запускались**: в среде разработки нет Flutter/Dart и Windows. Подробности и список непроверенного — в `HANDOFF.yaml`. Если фон панели чёрный, прозрачность потребует правки `windows/runner`.
