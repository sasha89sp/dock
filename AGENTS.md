# AGENTS.md — RocketDock Next

## Главная цель
Создать портативную Windows-панель приложений на Flutter/Dart, совместимую по пользовательскому сценарию с RocketDock 1.3.5.

## Архитектура
- Flutter / Dart, Clean Architecture, Feature-First.
- Windows — основная платформа.
- Все изменяемые данные рядом с EXE в `data/`; не использовать AppData, SharedPreferences или реестр для настроек.
- Нативные возможности Windows изолировать в `core/platform`.
- Не выполнять удалённые Git-операции.

## Правила
- Изучать существующий код перед изменениями.
- Минимизировать изменяемые файлы.
- Не добавлять зависимости без необходимости.
- Не утверждать, что проверки прошли, без фактического запуска.
- После каждой задачи обновлять `HANDOFF.yaml`.
- При изменении структуры обновлять `ROOT_MAP.md` и соответствующий `MAP.md`.

## План
1. Портативное хранение настроек и импорт RocketDock.
2. Полноценная панель и управление ярлыками.
3. Нативное прозрачное окно, поверх окон, позиционирование.
4. Автоскрытие, несколько мониторов, shell-иконки, полировка.

## Совместимость и ограничения
- Импортировать RocketDock portable `Settings.ini`, а также расположенные рядом `Icons`, `Skins`, `Docklets`.
- Неизвестные поля INI не интерпретировать наугад; добавлять предупреждения.
- Поддерживать пути к программам/файлам как ссылки, не копируя сами приложения.
- Docklets RocketDock не исполняются автоматически в RocketDock Next.
- Автозапуск и другие системные интеграции не должны незаметно менять реестр в портативном режиме.
- Не заявлять полную эквивалентность RocketDock до реализации и тестирования Win32 функций.
